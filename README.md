# G beauté — versão Vercel

Recriação da landing page a partir dos prints enviados.

## Publicar no GitHub/Vercel

1. Crie um repositório no GitHub.
2. Envie todos os arquivos desta pasta.
3. Na Vercel, importe o repositório.
4. Framework: Vite.
5. Build: `npm run build`
6. Output: `dist`

Não depende do Base44 para funcionar depois de publicado.

> As fotos usadas nesta versão foram recortadas dos screenshots enviados. Para uma versão final, substitua por arquivos originais das fotos do cliente para máxima qualidade.
